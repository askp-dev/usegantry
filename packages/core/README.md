# @usegantry/cli

Launch-readiness scanner for AI-generated repos: security, privacy, legal and cost checks in one CLI. Requires [Bun](https://bun.sh) ≥ 1.2.

```bash
bunx @usegantry/cli scan .
bunx @usegantry/cli check https://github.com/owner/repo
bunx @usegantry/cli roast https://github.com/owner/repo
```
